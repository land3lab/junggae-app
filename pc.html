아들이 쓰던 10년 전 컴퓨터도 쌩쌩하게 · 진단 → 처방 → 실행 → 전후 비교

똥컴닥터 v1.0 무료

사무실·상담실의 느린 윈도우 PC를 자동으로 진단하고, 0원 청소부터 SSD·메모리 교체, ChromeOS Flex 전환까지 처방전을 만들어 줍니다. 설치 없이 실행되는 윈도우 프로그램입니다.

Windows 10 / 11 · 24KB · 설치 불필요 (PowerShell 기본 기능만 사용)

⬇ 프로그램 받기

1지금 이 기기 간이 확인

브라우저로는 CPU 개수·메모리(대략)·윈도우 버전까지만 보입니다. 저장장치(HDD/SSD)·부팅시간·시작프로그램은 프로그램에서 정확히 진단합니다.

2실행 방법 (1분)

  1. [프로그램 받기] → 받은 파일을 오른쪽 클릭 → 압축 풀기 (압축 안에서 바로 실행하면 안 됩니다)
  2. 실행.bat 더블클릭
  3. "디바이스를 변경하도록 허용" 창 → [예]
  4. 파란 창 'Windows의 PC 보호'가 뜨면 → [추가 정보] → [실행]
  5. 프로그램에서 탭 순서대로: 진단 → 질문 3개 → 처방전 → 처방 A 실행 → 전후 비교·리포트
회사 PC에서 실행이 막히면, 받은 zip 파일 오른쪽 클릭 → [속성] → 아래 [차단 해제] 체크 → 확인 후 다시 압축을 푸세요.

3프로그램이 하는 일

① 진단CPU·메모리 규격·빈 슬롯·HDD/SSD·C드라이브 여유·부팅시간·시작프로그램·임시파일 → 건강점수
② 질문 3개주 용도(웹/한글·엑셀/등기소·은행) · 예산 0·5·10만원 · 자료 백업 여부
③ 처방전A 0원 청소 · B SSD·메모리(규격 자동 추천) · C ChromeOS Flex/Linux Mint
④ 처방 A 실행체크한 항목만 버튼 하나로 — 실행 전 복원지점 자동 생성
⑤ 전후 비교처음 진단 vs 지금, 재부팅 후 부팅시간 변화까지
⑥ 처방 리포트사무소 정보가 들어간 처방전을 바탕화면에 저장 → 인쇄·PDF

4처방 기준 한눈에

시작프로그램 많음·임시파일 쌓임A0원 청소 — 시작프로그램 끄기, 임시파일·휴지통, 기본 앱 제거, 전원·시각효과
하드디스크(HDD) 사용BSSD 교체 1순위 — 체감 효과가 가장 큼 (노트북은 2.5인치 SATA 그대로 교체)
메모리 8GB 미만B같은 규격(DDR3/4/5·노트북용/데스크톱용) 8GB 증설 — 빈 슬롯 자동 확인
웹·유튜브만 사용 (특히 Windows 10)CChromeOS Flex 전환 추천 — 백업 체크리스트 5개 통과 후 설치 안내
인터넷등기소·은행·한글(HWP) 사용C 비추천윈도우 유지 + A·B — 보안프로그램·한글은 윈도우 전용
부품 가격은 2025년 말부터 메모리·SSD 값이 크게 올라 변동이 심합니다. 처방전의 참고가는 구매 전 다나와 등에서 다시 확인하세요.

5안전장치

  1. 설정을 바꾸기 직전 윈도우 복원지점을 자동으로 만듭니다. 못 만들면 설정 변경은 건너뛰고 파일 청소만 합니다.
  2. 시작프로그램은 삭제가 아니라 작업관리자와 같은 방식의 끄기입니다. 보안프로그램(TouchEn·Veraport 등)·드라이버는 '유지 권장'으로 표시합니다.
  3. [되돌리기] 버튼으로 시작프로그램·전원·시각효과를 원래대로 돌립니다. (제거한 기본 앱은 Microsoft Store에서 다시 설치)
  4. 서비스 삭제·레지스트리 청소 같은 위험한 작업은 하지 않습니다. 운영체제 전환은 백업 확인 없이는 안내가 열리지 않습니다.
