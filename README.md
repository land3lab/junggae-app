# 중개사무소 앱

중개사가 공짜로, 한 화면에서 쓰는 실전 도구 10종 (랜드3 연구소).

- `index.html` — 탭형 대시보드(홈 요약 + 도구 탭, 각 도구는 `?embed=1`로 iframe에 표시). 새 도구는 `TOOLS` 배열에 page·state만 추가
- `lh.html` — ⑤ LH 전세임대 사전점검 신호등
- `dabang.html` — ② 다방광고 원클릭 (기기 저장, 주소→건축물대장 자동조회 `junggae_building`)
- `land.html` — ④ 토지 얼마나 해요? (토지특성·공시지가 `sise_land`, 토지 실거래 `sise_trades`, 키 미등록 시 국토부 CSV 업로드)
- `bid.html` — ⑦ 경매 입찰서류 자동작성 (새 기일입찰표 2026.11.2 양식 기준, 위임장·준비 확인서, 자릿수 대조판·이중입력 검사, 서버 없음·기기 저장 `bid.draft`/`bid.history`)
- `gongsil.html` — ⑥ 공실클럽(RSA 동문 전용): 공실 등록·지도(Leaflet/OSM)·문의 일지·14일 신선도, RPC `gs_*`, 동문 확인은 `lh.rsa_roster`(휴대폰 sha256 앞 40자 + 기수·권역) 대조, 미등록자는 관리자 승인. SQL: `sql/gongsil.sql`
- `shorts.html` — ③ AI쇼츠 만들기: ② 매물장(`d1c.listings`·IndexedDB `d1c` 사진) 또는 직접 입력 → 훅·본문·마무리 대본(금지어 검사) → 내 목소리 녹음(선택) → 캔버스 720×1280 렌더 + MediaRecorder(MP4 우선, 안 되면 WebM) → 4개 확인 후 승인 → 공유(유튜브 앱)/저장 + 제목·설명(표시사항 포함)·태그. 서버 없음, 기록 `sh.history`(② 거래완료 시 내림 알림)
- `blog.html` — ⑧ 블로그 자동생성: 글 종류 4종(매물 소개·동네 소개·부동산 상식 7주제·상담 사례) → 템플릿 생성(문장 변형 시드) 또는 AI 다듬기(claude 안에선 바로, 밖에선 요청문 복사→답 붙여넣기) → 제목 5안·본문(■ 소제목·[사진 n]·표·Q/A)·태그 → 검사(키워드 위치·횟수, 글자수, 사진, 금지어, 호수, 표시사항·사무소 정보, 사례 동의) → 서식 포함 복사(네이버 에디터)·워터마크 사진 ZIP → 발행 기록 `bl.history`(주간 목표, ② 거래완료 시 글 정리 알림, 글 없는 매물 추천). 서버 없음, ② `d1c.listings`·`d1c.office`·IndexedDB `d1c` 사진 공유
  - 매물 글 작성 지침(화면 4번 칸에 표시·생성·AI 요청문·검사에 반영): ① 제목 = 동네·유형·거래 형태 + 가격/입주일(예: `봉천동 투룸 전세 2억1천만 원 | 즉시 입주`) ② 첫 문단에 가격·관리비(포함/별도)·전용면적·입주 가능일, 소제목 `비용`·`집 구조와 사진`·`주차와 방문` ③ 장점은 실제 사진·확인한 사실, 주차 방식·엘리베이터·반려동물 표기, 미확인(보증보험 등)은 `확인 필요` ④ 공백 제외 2,000자 내외(1,700~2,400자)
  - 🎨 카드 이미지: 완성된 본문을 읽어 표지·요약표·체크리스트·자주 묻는 질문·상담 안내 카드(1080×1080, 주황/네이비/베이지)를 캔버스로 그려 본문에 `[카드 n]`으로 넣음, 최대 6장, IndexedDB `bl`의 `cards`. 매물 내부 사진은 생성하지 않음(허위·과장 광고 방지). ZIP에 `키워드-카드-01.jpg`로 함께 담김
- `maemul.html` — ⑨ 매물장(나만 보는 매물 장부): 등록(사진 8장·🔒동호수·의뢰인/동의), 상태 접수→광고중→계약진행→계약완료·보류·철회, 광고 기록(채널별 만료·내림 확인), 14일 확인, 목록/지도, CSV 가져오기·내보내기, ② 다방광고 매물 옮기기(`d1c.listings`+IndexedDB 사진), ②로 보내기(`d1c.draft`+IndexedDB `draft`), ⑥ 공실클럽 올리기(`gs_save`, 호수·의뢰인 제외), ⑩ 맞는 손님(`jg.match`). RPC `mj_*`
- `crm.html` — ⑩ 고객관리: 고객 종류·온도(A/B/C/휴면)·찾는 조건, 상담 일지(안내 매물·반응·다음 연락일), 매물장 자동 매칭(점수)·추천 문자, 계약·중도금·잔금·만기(6·3개월 전) 일정, vCard/CSV 가져오기, 종료 고객 파기. RPC `cr_*`. 허브 홈 요약 `jg_today`. SQL: `sql/maemul_crm.sql`(모두 본인만 조회, 주민번호 패턴 저장 거부)
- `land3.css` + `img/` — 랜드3 연구소 공통 디자인(명함 로고: 주황 #F77235·차콜 #23292B). 모든 화면이 `<style>` 뒤에 불러와 색 변수·머리글만 덮어씀
- 백엔드: Supabase(yangseongi 프로젝트 `lh` 스키마, 공개 RPC `lh_*`·`sise_*`·`junggae_*`, 공용 로그인)
- 정적 사이트 — 빌드 없음. Vercel에서 Framework "Other"로 그대로 배포.
